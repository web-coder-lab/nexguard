# NEXGUARD 1.0.3

## What is new

- Settings footer uses the real version from `BuildConfig`.
- English interface uses monitoring wording.
- New installs exclude system apps from monitoring by default.
- Backup rules exclude the local notification database and preferences.
- About section shows version, GitHub link, and GPL-3.0-only.

## Install

1. Download `NEXGUARD-1.0.3.apk` from this release after it is published.
2. Allow installation from your file source if Android asks.
3. Install over 1.0.1 or 1.0.2 if the signing certificate matches.
4. Grant notification access.

## Limits

NEXGUARD cannot recover a notification that never reached the phone, and it cannot force another app to stay alive.
